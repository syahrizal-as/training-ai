3.1 Definisi Generative AI

Apa itu Generative AI?

Generative AI (GenAI) adalah cabang artificial intelligence yang berfokus pada menghasilkan konten baru (teks, gambar, audio, video, kode) berdasarkan pola yang dipelajari dari data training. Berbeda dengan AI diskriminatif yang hanya mengklasifikasikan atau memprediksi, generative AI menciptakan sesuatu yang belum pernah ada sebelumnya.

Karakteristik Utama

🆕 Menghasilkan Konten Baru

Output bersifat orisinal, bukan sekadar copy-paste dari data training

📊 Data-Driven

Belajar dari distribusi data training untuk menghasilkan sampel baru

🌐 Multi-Modal

Dapat menangani teks, gambar, audio, video, dan kode

🎯 Promptable

Diarahkan melalui instruksi bahasa alami (prompt)

AI Diskriminatif vs AI Generatif

AspekAI DiskriminatifAI Generatif
TujuanMembedakan / mengklasifikasikanMenciptakan / menghasilkan
PendekatanP(Y|X) — mempelajari batas keputusanP(X) atau P(X|Y) — mempelajari distribusi data
Contoh ModelResNet, YOLO, XGBoostGPT-4o, Stable Diffusion, Sora

📖 Analogi: AI Diskriminatif seperti kritikus seni yang bisa membedakan lukisan Monet dari Van Gogh. AI Generatif seperti pelukis yang bisa menciptakan lukisan baru dalam gaya Monet — sesuatu yang belum pernah ada sebelumnya.

3.2 Cara Kerja: Training & Inference

Fase Training

Training adalah proses di mana model mempelajari pola dan struktur dari dataset masif. Untuk Large Language Models (LLM), training dilakukan dalam beberapa tahap:

  1. Pre-training (unsupervised): Model belajar dari triliunan token teks dari internet, buku, dan kode. Pada tahap ini model belajar next-token prediction — memprediksi kata berikutnya dalam urutan.
  2. Fine-tuning (supervised): Model dilatih lebih lanjut dengan dataset berkualitas tinggi berisi pasangan prompt-response untuk meningkatkan kemampuannya mengikuti instruksi.
  3. Alignment (RLHF/DPO): Model diselaraskan dengan preferensi manusia menggunakan Reinforcement Learning from Human Feedback (RLHF) atau Direct Preference Optimization (DPO).
⚠️ Biaya Komputasi: Training GPT-4 diperkirakan membutuhkan >25,000 GPU NVIDIA A100 selama 90-100 hari, dengan biaya listrik dan hardware mencapai ratusan juta dolar. Ini sebabnya hanya sedikit organisasi yang mampu membangun model frontier dari nol.

Fase Inference

Inference adalah proses di mana model yang sudah dilatih menghasilkan output berdasarkan input pengguna (prompt). Ini melibatkan:

  • Tokenization: Input prompt dipecah menjadi token
  • Forward pass: Token diproses melalui jaringan neural untuk menghasilkan distribusi probabilitas token berikutnya
  • Sampling: Token dipilih berdasarkan probabilitas (dipengaruhi oleh temperature, top-p, top-k)
  • Autoregressive generation: Token yang dihasilkan ditambahkan ke input, proses diulang sampai token stop atau batas panjang tercapai

3.3 Konsep Fundamental: Prompt, Token, Context Window

Prompt

Prompt adalah input teks yang diberikan ke model generative AI untuk mengarahkan output-nya. Prompt bisa berupa pertanyaan, instruksi, deskripsi, atau kombinasi semuanya. Kualitas prompt sangat mempengaruhi kualitas output — inilah mengapa Prompt Engineering menjadi keterampilan penting dalam era AI.

❌ Prompt Buruk

Tulis tentang AI.

Terlalu umum, tidak ada konteks, output tidak terarah.

✅ Prompt Baik

Jelaskan 3 aplikasi utama Generative AI di industri kesehatan. Gunakan bahasa Indonesia, sertakan contoh konkret untuk setiap aplikasi. Format dalam bullet points.

Spesifik, terstruktur, dengan format output yang jelas.

Token

Token adalah unit terkecil teks yang diproses oleh model bahasa. Token bukan kata utuh — satu kata bisa dipecah menjadi beberapa token, dan sebaliknya. Token adalah "mata uang" LLM: model dibatasi oleh jumlah token yang bisa diproses (context window) dan biasanya biaya API dihitung per token.

TeksJumlah TokenPenjelasan
Halo dunia!~3-4 tokenKata pendek = 1 token per kata
Mempertanggungjawabkan~5-6 tokenKata panjang = dipecah beberapa token
Hello, world!~3 tokenBahasa Inggris lebih efisien token
💡 Aturan praktis: 1 token ≈ 0.75 kata dalam bahasa Inggris, ≈ 0.5 kata dalam bahasa Indonesia (karena banyak kata majemuk). 1,000 token ≈ 750 kata bahasa Inggris.

Context Window

Context Window adalah jumlah maksimum token yang dapat "diingat" dan diproses oleh model dalam satu kali inference. Ini mencakup prompt input + output yang dihasilkan. Context window adalah "memori kerja" model — semakin besar, semakin banyak informasi yang bisa dipertimbangkan model dalam menghasilkan respons.

3.4 Parameter Generasi: Temperature & Top-P

Temperature

Temperature adalah parameter yang mengontrol kreativitas dan keacakan output model. Temperature bekerja dengan "meratakan" atau "menajamkan" distribusi probabilitas token sebelum sampling.

  • Temperature → 0: Model menjadi deterministik — selalu memilih token dengan probabilitas tertinggi. Output konsisten, cocok untuk faktual / kode.
  • Temperature = 1.0: Distribusi probabilitas tidak diubah — keseimbangan antara kreativitas dan akurasi.
  • Temperature > 1.0: Model menjadi kreatif dan tidak terduga — token probabilitas rendah mendapat kesempatan lebih besar. Cocok untuk brainstorming, cerita kreatif.
Use CaseTemperature
Kode / SQL / Matematika0.0 - 0.2
Analisis / Ringkasan0.3 - 0.5
Chat / Tanya Jawab0.5 - 0.7
Kreatif / Brainstorming0.8 - 1.2
Cerita / Puisi1.0 - 1.5

Top-P (Nucleus Sampling)

Top-P (juga disebut Nucleus Sampling) adalah metode sampling alternatif yang membatasi pilihan token hanya pada kumulatif probabilitas tertentu. Alih-alih mempertimbangkan semua token, model hanya memilih dari sekumpulan token terkecil yang probabilitas kumulatifnya ≥ P.

3.7 Ringkasan

  • Generative AI menciptakan konten baru berdasarkan pola dari data training, berbeda dari AI diskriminatif yang hanya mengklasifikasikan.
  • Pipeline Generative AI terdiri dari: training (pre-training → fine-tuning → alignment) dan inference (tokenization → forward pass → sampling → autoregressive generation).
  • Prompt adalah input instruksi; Token adalah unit teks terkecil; Context Window adalah kapasitas memori model dalam satu sesi.
  • Temperature mengontrol kreativitas (0=deterministik, 1=kreatif); Top-P membatasi pilihan token ke nucleus probabilitas kumulatif.
  • Model frontier (GPT-4o, Gemini 2.5 Pro, Claude 3.5 Sonnet) vs model open-source (Llama 3, DeepSeek-V3, Qwen 2.5, Mistral Large) — pilihan bergantung pada budget, kebutuhan context window, dan kebutuhan self-hosting.

🏋️ Latihan

  1. Eksperimen Temperature: Gunakan playground OpenAI/Gemini dengan prompt yang sama, coba temperature 0.0, 0.5, dan 1.2. Bandingkan output-nya. Catat perbedaan dalam hal kreativitas, konsistensi, dan faktualitas.
  2. Hitung Token: Ambil 3 paragraf teks dari artikel berita. Gunakan OpenAI Tokenizer untuk menghitung jumlah token. Bandingkan dengan jumlah kata dan karakter.
  3. Perbandingan Model: Berikan prompt yang sama ke setidaknya 3 model berbeda (GPT-4o, Claude, Gemini). Evaluasi: mana yang paling akurat, paling kreatif, paling cepat?
  4. Top-P Eksperimen: Dengan temperature=1.0, coba top_p=0.5 vs top_p=1.0. Amati perbedaan variasi output.
