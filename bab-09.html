9.1 Definisi & Motivasi MCP

Definisi MCP

Model Context Protocol (MCP) adalah protokol terbuka (open protocol) yang distandarisasi oleh Anthropic untuk menghubungkan AI model dengan tools dan sumber data eksternal. MCP menyediakan antarmuka standar bagi AI applications untuk mengakses konteks — seperti database, API, file system, dan layanan eksternal — melalui arsitektur client-server yang aman.

📖 Analogi: MCP adalah seperti "USB-C untuk AI." Seperti USB-C menjadi standar universal untuk koneksi perangkat keras, MCP menjadi standar universal untuk koneksi AI ke tools dan data. Satu protokol, banyak implementasi.

Motivasi: Masalah yang Dipecahkan MCP

Tanpa MCPDengan MCP
Setiap integrasi AI-tool membutuhkan kode kustomSatu protokol standar untuk semua tools
Vendor lock-in pada ekosistem LLM tertentuInteroperabilitas antar provider AI
Fragmentasi — setiap framework punya caranya sendiriStandar terbuka, komunitas-driven
Keamanan tidak terstandarisasiModel keamanan built-in (auth, permission)

9.2 Arsitektur MCP

MCP menggunakan arsitektur client-server dengan komunikasi berbasis JSON-RPC 2.0. MCP Host (aplikasi AI seperti Claude Desktop, IDE, atau custom app) menjalankan satu atau lebih MCP Client yang terhubung ke MCP Server melalui transport protocol (stdio atau HTTP/SSE).

Setiap MCP Server menyediakan kemampuan spesifik (tools, resources, prompts). MCP Client bertindak sebagai jembatan yang menerjemahkan tool calls dari AI model menjadi request JSON-RPC yang dikirim ke MCP Server yang tepat.

9.3 Komponen MCP

9.3.1 MCP Client

MCP Client adalah komponen yang berjalan di sisi MCP Host, bertanggung jawab untuk mengelola koneksi ke MCP Server, mengirim request, dan menerima response. Client menangani lifecycle connection (connect, initialize, disconnect) dan menyediakan interface bagi AI model untuk menemukan dan memanggil tools.

9.3.2 MCP Server

MCP Server adalah proses independen yang mengekspos capabilities (tools, resources, prompts) melalui protokol JSON-RPC 2.0. Server dapat dibangun dalam bahasa apa pun (Python, TypeScript, Go, Rust) dan berkomunikasi via stdio (subprocess) atau HTTP dengan Server-Sent Events (SSE).

9.3.3 Tool

Tool adalah fungsi yang dapat dipanggil oleh AI model melalui MCP. Setiap tool memiliki:

  • Name: Identifier unik tool
  • Description: Deskripsi yang membantu AI model memahami kapan menggunakan tool
  • Input Schema: JSON Schema yang mendefinisikan parameter input
  • Handler: Fungsi yang dieksekusi saat tool dipanggil

9.3.4 Resource

Resource adalah data kontekstual yang diekspos oleh MCP Server. Berbeda dengan Tool (fungsi/aksi), Resource menyediakan akses read-only ke data. Contoh: isi file, hasil query database, konfigurasi sistem. Resource diidentifikasi dengan URI (contoh: file:///docs/readme.txt, db://users/list).

9.3.5 Prompt

Prompt adalah template prompt yang telah dikurasi dan dapat digunakan kembali. MCP Server dapat menyediakan prompt templates yang terstandarisasi untuk use case tertentu, memudahkan user atau AI model untuk memulai interaksi dengan format yang benar.

9.3.6 Sampling

Sampling adalah fitur yang memungkinkan MCP Server untuk meminta MCP Client melakukan LLM inference. Ini membalikkan arah komunikasi normal: Server bisa meminta Client untuk "menyelesaikan" prompt tertentu menggunakan LLM yang tersedia di sisi Client.

9.5 Contoh Implementasi

9.5.1 MCP Server (Python)

# server.py - MCP Server sederhana untuk weather & calculator
from mcp.server import Server, NotificationOptions
from mcp.server.models import InitializationCapabilities
import mcp.server.stdio
import mcp.types as types
import json, httpx

server = Server("weather-calc-server")

# ============ TOOLS ============

@server.list_tools()
async def handle_list_tools() -> list[types.Tool]:
    return [
        types.Tool(
            name="get_weather",
            description="Get current weather for a city. Use Celsius.",
            inputSchema={
                "type": "object",
                "properties": {
                    "city": {
                        "type": "string",
                        "description": "City name, e.g., 'Jakarta'"
                    }
                },
                "required": ["city"]
            }
        ),
        types.Tool(
            name="calculate",
            description="Evaluate a mathematical expression",
            inputSchema={
                "type": "object",
                "properties": {
                    "expression": {
                        "type": "string",
                        "description": "Math expression, e.g., '2 + 2 * 3'"
                    }
                },
                "required": ["expression"]
            }
        )
    ]

@server.call_tool()
async def handle_call_tool(
    name: str, arguments: dict
) -> list[types.TextContent]:
    if name == "get_weather":
        city = arguments["city"]
        # Simulasi API call (ganti dengan API sungguhan)
        async with httpx.AsyncClient() as client:
            resp = await client.get(
                f"https://wttr.in/{city}?format=j1"
            )
            data = resp.json()
            temp = data["current_condition"][0]["temp_C"]
            desc = data["current_condition"][0]["weatherDesc"][0]["value"]
        
        return [types.TextContent(
            type="text",
            text=f"🌤️ Weather in {city}: {temp}°C, {desc}"
        )]
    
    elif name == "calculate":
        expression = arguments["expression"]
        try:
            result = eval(expression)  # Hati-hati: gunakan safe eval di production
            return [types.TextContent(
                type="text",
                text=f"🧮 {expression} = {result}"
            )]
        except Exception as e:
            return [types.TextContent(
                type="text",
                text=f"Error: {str(e)}"
            )]

# ============ RESOURCES ============

@server.list_resources()
async def handle_list_resources() -> list[types.Resource]:
    return [
        types.Resource(
            uri="weather://supported-cities",
            name="Supported Cities",
            description="List of cities with weather data",
            mimeType="application/json"
        )
    ]

@server.read_resource()
async def handle_read_resource(uri: str) -> str:
    if uri == "weather://supported-cities":
        return json.dumps(["Jakarta", "Surabaya", "Bandung", "Medan"])

# ============ RUN SERVER ============

async def main():
    async with mcp.server.stdio.stdio_server() as (read, write):
        await server.run(
            read, write,
            InitializationCapabilities(
                sampling={},
                experimental={},
                tools={},
                resources={}
            )
        )

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())

9.5.2 MCP Client (Python)

# client.py - MCP Client sederhana
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    # Buat koneksi ke MCP Server melalui stdio
    server_params = StdioServerParameters(
        command="python",
        args=["server.py"]
    )
    
    async with stdio_client(server_params) as (read, write):
        async with ClientSession(read, write) as session:
            # 1. Initialize
            await session.initialize()
            
            # 2. List available tools
            tools_result = await session.list_tools()
            print("Available tools:")
            for tool in tools_result.tools:
                print(f"  - {tool.name}: {tool.description}")
            
            # 3. List available resources
            resources = await session.list_resources()
            print("\nAvailable resources:")
            for resource in resources.resources:
                print(f"  - {resource.uri}: {resource.name}")
            
            # 4. Call a tool
            print("\n--- Calling get_weather ---")
            result = await session.call_tool(
                "get_weather",
                arguments={"city": "Jakarta"}
            )
            print(f"Result: {result.content[0].text}")
            
            # 5. Call another tool
            print("\n--- Calling calculate ---")
            result = await session.call_tool(
                "calculate",
                arguments={"expression": "15 * 3 + 7"}
            )
            print(f"Result: {result.content[0].text}")
            
            # 6. Read a resource
            print("\n--- Reading resource ---")
            resource_content = await session.read_resource(
                "weather://supported-cities"
            )
            print(f"Cities: {resource_content.contents[0].text}")

if __name__ == "__main__":
    asyncio.run(main())

9.5.3 MCP Server (TypeScript)

// server.ts - MCP Server dengan TypeScript
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
  ListResourcesRequestSchema,
  ReadResourceRequestSchema,
} from "@modelcontextprotocol/sdk/types.js";

const server = new Server(
  { name: "ts-weather-server", version: "1.0.0" },
  { capabilities: { tools: {}, resources: {} } }
);

// Register tools
server.setRequestHandler(ListToolsRequestSchema, async () => ({
  tools: [
    {
      name: "get_weather",
      description: "Get current weather for a city in Celsius",
      inputSchema: {
        type: "object",
        properties: {
          city: { type: "string", description: "City name" }
        },
        required: ["city"]
      }
    },
    {
      name: "get_time",
      description: "Get current time for a timezone",
      inputSchema: {
        type: "object",
        properties: {
          timezone: { 
            type: "string", 
            description: "Timezone, e.g., 'Asia/Jakarta'" 
          }
        },
        required: ["timezone"]
      }
    }
  ]
}));

server.setRequestHandler(CallToolRequestSchema, async (request) => {
  const { name, arguments: args } = request.params;
  
  switch (name) {
    case "get_weather": {
      const city = args?.city as string;
      // Simulasi — gunakan API sungguhan di production
      return {
        content: [{
          type: "text",
          text: `🌤️ Weather in ${city}: 28°C, Partly Cloudy`
        }]
      };
    }
    case "get_time": {
      const tz = args?.timezone as string || "Asia/Jakarta";
      const time = new Date().toLocaleString("id-ID", { timeZone: tz });
      return {
        content: [{
          type: "text",
          text: `🕐 Current time in ${tz}: ${time}`
        }]
      };
    }
    default:
      throw new Error(`Unknown tool: ${name}`);
  }
});

// Register resources
server.setRequestHandler(ListResourcesRequestSchema, async () => ({
  resources: [{
    uri: "config://server-info",
    name: "Server Information",
    mimeType: "application/json"
  }]
}));

server.setRequestHandler(ReadResourceRequestSchema, async (request) => {
  if (request.params.uri === "config://server-info") {
    return {
      contents: [{
        uri: request.params.uri,
        mimeType: "application/json",
        text: JSON.stringify({
          name: "TS Weather Server",
          version: "1.0.0",
          uptime: process.uptime()
        })
      }]
    };
  }
  throw new Error(`Unknown resource: ${request.params.uri}`);
});

// Start server
async function main() {
  const transport = new StdioServerTransport();
  await server.connect(transport);
  console.error("MCP Server running on stdio");
}

main().catch(console.error);

9.6 MCP & AI Agent

MCP memainkan peran penting dalam ekosistem AI Agent (yang akan dibahas di BAB 10). Dalam arsitektur AI Agent, MCP berfungsi sebagai standardized tool interface yang memungkinkan Agent untuk:

  • Discover tools dynamically: Agent dapat menemukan tools yang tersedia tanpa hardcoding
  • Access diverse data sources: Database, API, file system — semua melalui satu protokol
  • Switch between AI providers: Agent yang sama dapat menggunakan Claude, GPT, atau model lain tanpa mengubah integrasi tool
  • Compose complex workflows: Multiple MCP servers dapat dikomposisikan untuk membentuk workflow multi-step

🔗 Ecosystem: MCP SDK tersedia untuk Python, TypeScript, Kotlin, dan C#. Tools populer seperti Claude Desktop, Cursor, Continue.dev, dan Zed telah mengadopsi MCP sebagai standar integrasi.

9.7 Best Practice

Best PracticePenjelasan
Tool descriptions yang jelasDeskripsi tool adalah prompt engineering. Tulis deskripsi yang menjelaskan kapan tool digunakan, apa input-nya, dan apa output-nya. AI model membaca deskripsi ini untuk memutuskan tool mana yang dipanggil.
Input schema yang ketatGunakan JSON Schema yang lengkap dengan type, description, enum, dan constraints. Semakin ketat schema, semakin kecil kemungkinan AI salah menggunakan tool.
Error handling yang informatifReturn error messages yang jelas dan dapat digunakan AI untuk koreksi diri. Jangan return generic "Error occurred."
Satu server, satu domainSetiap MCP Server sebaiknya fokus pada satu domain (database, filesystem, search). Komposisikan multiple server untuk workflow kompleks.
Gunakan transport yang tepatstdio untuk local subprocess (low latency, simple). HTTP/SSE untuk remote server (networked, scalable).
Rate limiting & timeoutImplementasikan rate limiting dan timeout di MCP Server untuk mencegah abuse dan memastikan responsivitas.
Logging & monitoringLog semua tool calls dengan timestamp, arguments, dan hasil untuk debugging dan audit trail.

9.8 Ringkasan

  • MCP (Model Context Protocol) adalah protokol terbuka standar untuk menghubungkan AI model dengan tools dan data eksternal melalui arsitektur client-server.
  • Komponen utama MCP: Client (jembatan), Server (penyedia capabilities), Tool (fungsi yang dapat dipanggil), Resource (data read-only), Prompt (template), Sampling (server-triggered LLM inference).
  • Komunikasi: JSON-RPC 2.0 over stdio (local) atau HTTP/SSE (remote).
  • MCP & Agent: MCP menyediakan standardized tool interface yang memungkinkan AI Agent menemukan dan menggunakan tools secara dinamis.
  • Best practice: Tool descriptions yang jelas, input schema ketat, error handling informatif, satu server per domain, transport yang tepat.
