6.1 Apa itu Embedding?

Definisi

Embedding adalah representasi vektor numerik berdimensi tetap (dense vector) dari data — teks, gambar, audio — dalam ruang vektor kontinu. Vektor embedding menangkap makna semantik dari data: teks yang secara semantik mirip akan memiliki vektor yang berdekatan dalam vector space, sedangkan teks yang berbeda makna akan berjauhan.

📖 Bedakan dua jenis embedding:
  • Token Embedding (Bab 4): Representasi vektor individual token di dalam LLM, dipelajari selama training sebagai bagian dari model.
  • Text Embedding (Bab ini): Satu vektor untuk seluruh teks/dokumen, dihasilkan oleh embedding model khusus, digunakan untuk search, clustering, dan retrieval.

Mengapa Embedding Penting?

Komputer tidak memahami teks secara langsung — mereka hanya memahami angka. Embedding menjembatani kesenjangan antara bahasa manusia dan komputasi numerik. Dengan embedding, kita bisa:

  • Mencari berdasarkan makna (bukan keyword) — Semantic Search
  • Mengelompokkan dokumen yang mirip secara otomatis — Clustering
  • Mendeteksi duplikat atau near-duplicate content
  • Memberikan konteks ke LLM melalui Retrieval-Augmented Generation (RAG)
  • Klasifikasi teks tanpa training ulang

Proses Embedding

# Contoh: Konversi teks ke embedding menggunakan OpenAI API
from openai import OpenAI
client = OpenAI()

def get_embedding(text: str, model: str = "text-embedding-3-small") -> list[float]:
    """Mengonversi teks menjadi vektor embedding."""
    text = text.replace("\n", " ")
    response = client.embeddings.create(
        input=[text],
        model=model
    )
    return response.data[0].embedding

# Contoh penggunaan
teks1 = "Kucing adalah hewan peliharaan yang lucu"
teks2 = "Anjing adalah hewan peliharaan yang setia"
teks3 = "Harga saham teknologi naik 5% hari ini"

emb1 = get_embedding(teks1)  # 1536 dimensi
emb2 = get_embedding(teks2)  # 1536 dimensi
emb3 = get_embedding(teks3)  # 1536 dimensi

# teks1 dan teks2 akan lebih mirip (keduanya tentang hewan peliharaan)
# teks3 akan jauh berbeda (tentang pasar saham)
💡 Pooling Strategy: Embedding model menghasilkan vektor untuk setiap token. Untuk mendapatkan satu vektor untuk seluruh teks, digunakan pooling: Mean Pooling (rata-rata semua token) atau [CLS] Token (token klasifikasi khusus). Mean pooling umumnya lebih robust untuk semantic search.

6.3 Vector Space

Konsep Vector Space

Vector Space adalah ruang multi-dimensi tempat vektor embedding berada. Setiap dimensi merepresentasikan fitur semantik tertentu yang dipelajari model. Dalam vector space, arah (direction) vektor lebih penting daripada magnitudenya — dua vektor yang menunjuk ke arah yang sama memiliki makna serupa, terlepas dari panjangnya.

Dalam praktiknya, vector space berdimensi tinggi (768, 1536, atau 3072) — bukan 2D seperti ilustrasi di atas. Dimensi tinggi memungkinkan representasi yang jauh lebih kaya dan nuanced.

6.4 Similarity Metrics

Cosine Similarity

Cosine Similarity mengukur kesamaan arah dua vektor, tanpa memperhatikan magnitudenya. Nilai cosine similarity berkisar dari -1 (berlawanan arah) hingga 1 (arah identik), dengan 0 berarti ortogonal (tidak terkait). Ini adalah metrik paling umum untuk embedding karena fokus pada arah semantik, bukan panjang vektor.

import numpy as np

def cosine_similarity(vec1: np.ndarray, vec2: np.ndarray) -> float:
    """
    Cosine Similarity = (A · B) / (||A|| × ||B||)
    
    - Nilai 1: vektor identik (arah sama persis)
    - Nilai 0: vektor ortogonal (tidak terkait)
    - Nilai -1: vektor berlawanan arah
    """
    dot_product = np.dot(vec1, vec2)
    norm_a = np.linalg.norm(vec1)
    norm_b = np.linalg.norm(vec2)
    return dot_product / (norm_a * norm_b)

# Contoh
v_cat = np.array([0.8, 0.6])
v_dog = np.array([0.7, 0.5])
v_stock = np.array([-0.5, 0.8])

print(f"Cat vs Dog: {cosine_similarity(v_cat, v_dog):.3f}")    # ~0.99 (mirip!)
print(f"Cat vs Stock: {cosine_similarity(v_cat, v_stock):.3f}") # ~0.02 (tidak terkait)

Euclidean Distance

Euclidean Distance mengukur jarak "garis lurus" antara dua titik dalam vector space. Berbeda dengan cosine similarity, Euclidean distance sensitif terhadap magnitude vektor. Dua vektor bisa memiliki arah yang sama tetapi jarak Euclidean yang besar jika panjangnya berbeda.

def euclidean_distance(vec1: np.ndarray, vec2: np.ndarray) -> float:
    """
    Euclidean Distance = sqrt(Σ(Ai - Bi)²)
    
    - Nilai 0: titik yang sama
    - Semakin besar: semakin jauh / berbeda
    """
    return np.sqrt(np.sum((vec1 - vec2) ** 2))

# Contoh
print(f"Cat vs Dog: {euclidean_distance(v_cat, v_dog):.3f}")    # ~0.14 (dekat)
print(f"Cat vs Stock: {euclidean_distance(v_cat, v_stock):.3f}") # ~1.28 (jauh)

Dot Product

Dot Product (inner product) mengukur kesamaan dua vektor tanpa normalisasi. Dot product mempertimbangkan baik arah maupun magnitude. Berguna ketika magnitude vektor memiliki makna (misalnya, vektor dengan magnitude lebih besar = konten lebih "informatif").

def dot_product(vec1: np.ndarray, vec2: np.ndarray) -> float:
    """
    Dot Product = Σ(Ai × Bi)
    
    - Semakin besar positif: semakin mirip
    - Mendekati 0: tidak terkait
    - Negatif: berlawanan
    """
    return np.dot(vec1, vec2)

MetrikRangeSensitif Magnitude?Use Case
Cosine Similarity-1 s/d 1❌ TidakSemantic search (default), document similarity
Euclidean Distance0 s/d ∞✅ YaClustering (K-means), anomaly detection

💡 Best Practice: Gunakan Cosine Similarity sebagai default untuk semantic search. Jika embedding sudah dinormalisasi (||v|| = 1), cosine similarity = dot product, dan keduanya bisa digunakan interchangeably.

6.5 Semantic Search

Keyword Search vs Semantic Search

Semantic Search mencari berdasarkan makna, bukan berdasarkan pencocokan kata kunci (keyword matching). Ini mengatasi keterbatasan fundamental keyword search di mana query dan dokumen menggunakan kata yang berbeda tetapi memiliki arti yang sama.

QueryKeyword SearchSemantic Search
"mobil hemat bensin"❌ Tidak menemukan "kendaraan irit bahan bakar"✅ Menemukan karena makna mirip
"cara mengatasi insomnia"❌ Tidak menemukan "tips tidur nyenyak"✅ Menemukan karena makna mirip

import numpy as np
from typing import list, tuple

def semantic_search(
    query_embedding: np.ndarray,
    document_embeddings: list[tuple[str, np.ndarray]],
    top_k: int = 5
) -> list[tuple[str, float]]:
    """
    Mencari dokumen paling relevan menggunakan embedding.
    """
    results = []
    for doc_id, doc_emb in document_embeddings:
        similarity = cosine_similarity(query_embedding, doc_emb)
        results.append((doc_id, similarity))
    
    # Urutkan berdasarkan similarity tertinggi
    results.sort(key=lambda x: x[1], reverse=True)
    return results[:top_k]

# Contoh penggunaan
query = "kendaraan hemat energi"
query_emb = get_embedding(query)

documents = [
    ("doc1", get_embedding("Mobil hybrid paling irit BBM tahun 2026")),
    ("doc2", get_embedding("Resep kue coklat yang mudah dibuat")),
    ("doc3", get_embedding("Motor listrik dengan jarak tempuh terjauh")),
]

results = semantic_search(query_emb, documents, top_k=2)
for doc_id, score in results:
    print(f"{doc_id}: {score:.3f}")
# Output:
# doc1: 0.891
# doc3: 0.845
📖 Hybrid Search: Beberapa sistem menggabungkan semantic search (embedding) dengan keyword search (BM25/TF-IDF) untuk hasil terbaik — disebut hybrid search. Ini menangkap baik relevansi semantik maupun pencocokan kata kunci eksak (penting untuk query dengan nama produk, kode, atau istilah teknis spesifik).

6.7 Ringkasan

  • Embedding adalah representasi vektor numerik dari teks yang menangkap makna semantik — teks mirip memiliki vektor berdekatan.
  • Proses embedding: Teks → Tokenization → Embedding Model → Pooling → Vektor output (dimensi tetap).
  • Vector Space adalah ruang multi-dimensi di mana arah vektor merepresentasikan makna. Dimensi tinggi memungkinkan representasi nuanced.
  • Similarity Metrics: Cosine Similarity (default, fokus arah), Euclidean Distance (jarak absolut), Dot Product (arah + magnitude).
  • Semantic Search mencari berdasarkan makna, bukan kata kunci — mengatasi vocabulary mismatch antara query dan dokumen.
  • Embedding Models: text-embedding-3 (OpenAI) untuk dimensi fleksibel, Voyage (context window besar 32K), Cohere (spesialis bahasa), BGE/E5 (open-source).
