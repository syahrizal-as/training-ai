4.1 Definisi LLM

Apa itu Large Language Model?

Large Language Model (LLM) adalah model AI berbasis arsitektur Transformer yang dilatih pada dataset teks berskala sangat besar (triliunan token) untuk memahami dan menghasilkan bahasa manusia. Kata "Large" merujuk pada jumlah parameter model — mulai dari miliaran (1B) hingga triliunan — yang menentukan kapasitas model dalam menangkap pola bahasa yang kompleks.

📖 Definisi Teknis: LLM adalah model autoregressive yang memodelkan distribusi probabilitas token berikutnya dalam sebuah sekuens: P(tokent | token1, token2, ..., tokent-1). Model belajar memprediksi kata berikutnya berdasarkan konteks sebelumnya, dan kemampuan ini — ketika diskalakan — menghasilkan emergent abilities seperti reasoning, coding, dan translation.

4.2 Tokenisasi: BPE & WordPiece

Apa itu Tokenisasi?

Tokenisasi adalah proses mengonversi teks mentah menjadi urutan token yang dapat diproses oleh model. Token adalah unit dasar yang menjadi input dan output LLM. Tokenisasi yang baik harus menangani kosakata terbuka (termasuk kata yang belum pernah dilihat), efisien dalam representasi, dan dapat memproses berbagai bahasa.

Byte-Pair Encoding (BPE)

Byte-Pair Encoding (BPE) adalah algoritma tokenisasi sub-kata yang digunakan oleh GPT-series (GPT-2, GPT-3, GPT-4) dan Llama. BPE bekerja dengan:

  1. Mulai dari karakter individual sebagai kosakata awal
  2. Hitung frekuensi setiap pasangan token yang berdekatan
  3. Gabungkan pasangan paling sering menjadi token baru
  4. Ulangi langkah 2-3 sampai jumlah merge yang diinginkan tercapai
# Ilustrasi konseptual BPE
# Teks: "low low low low lower"
# Iterasi 1: Pasangan "l"+"o" paling sering → token "lo"
# Iterasi 2: Pasangan "lo"+"w" paling sering → token "low"
# Hasil: kosakata memiliki token "low" untuk efisiensi

# GPT-4 menggunakan tokenizer berbasis BPE dengan ~100K token
# Kata "mempertanggungjawabkan" → ["mem","pert","anggung","jawab","kan"]
💡 Kelebihan BPE: Menangani kata di luar kosakata (OOV) dengan memecahnya menjadi sub-kata yang dikenal. Kata baru seperti "ChatGPT" akan dipecah menjadi ["Chat", "G", "PT"] — semua sub-kata yang sudah ada di kosakata.

WordPiece

WordPiece adalah algoritma tokenisasi yang dikembangkan oleh Google, digunakan dalam BERT dan keluarga model Google. Berbeda dengan BPE yang memilih pasangan berdasarkan frekuensi murni, WordPiece memilih pasangan yang memaksimalkan likelihood data training.

4.3 Embedding

Apa itu Embedding?

Embedding adalah representasi vektor numerik (berdimensi tetap) dari token, kata, atau teks dalam ruang vektor kontinu. Di dalam LLM, setiap token ID yang dihasilkan oleh tokenizer dipetakan ke vektor embedding melalui embedding matrix (lookup table) yang dipelajari selama training. Vektor-vektor ini menangkap makna semantik — token yang semantik mirip akan memiliki vektor yang berdekatan dalam ruang embedding.

4.4 Arsitektur Transformer

Gambaran Umum

Arsitektur Transformer diperkenalkan dalam paper "Attention Is All You Need" (Vaswani et al., 2017) dan menjadi fondasi seluruh LLM modern. Transformer sepenuhnya meninggalkan recurrence (RNN/LSTM) dan hanya menggunakan mekanisme attention — memungkinkan pemrosesan paralel yang masif dan menangkap dependensi jarak jauh dalam teks.

Self-Attention

Self-Attention adalah mekanisme inti Transformer yang memungkinkan setiap token "memperhatikan" semua token lain dalam sekuens untuk menghitung representasi kontekstual. Setiap token menghasilkan tiga vektor:

  • Query (Q): "Apa yang saya cari?" — vektor yang merepresentasikan token saat ini sebagai pencari informasi
  • Key (K): "Apa yang saya tawarkan?" — vektor yang merepresentasikan token sebagai penyedia informasi
  • Value (V): "Informasi aktual" — vektor yang berisi konten informasi dari token
# Rumus Self-Attention (scaled dot-product attention)
# Attention(Q, K, V) = softmax(QK^T / √d_k) × V

# d_k = dimensi key (scaling factor)
# QK^T = matriks similarity antar semua pasangan token
# softmax = normalisasi menjadi distribusi probabilitas
# × V = weighted sum dari value vectors

import numpy as np

def self_attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]  # Dimensi key
    # Hitung attention scores
    scores = np.dot(Q, K.T) / np.sqrt(d_k)
    # Masking (untuk decoder: cegah melihat token masa depan)
    if mask is not None:
        scores = scores + mask
    # Softmax untuk mendapatkan attention weights
    attention_weights = np.exp(scores) / np.sum(np.exp(scores), axis=-1, keepdims=True)
    # Weighted sum of values
    output = np.dot(attention_weights, V)
    return output, attention_weights

Multi-Head Attention

Multi-Head Attention menjalankan beberapa mekanisme self-attention secara paralel dengan matriks Q, K, V yang berbeda di setiap "head". Setiap head dapat fokus pada aspek hubungan yang berbeda — satu head mungkin fokus pada hubungan sintaksis, head lain pada hubungan semantik, dan head lainnya pada dependensi jarak jauh.

Positional Encoding

Karena Transformer memproses semua token secara paralel (tidak seperti RNN yang sekuensial), model tidak memiliki informasi urutan bawaan. Positional Encoding menambahkan informasi posisi ke setiap token embedding menggunakan fungsi sinusoidal atau parameter yang dipelajari:

# Positional Encoding sinusoidal (original Transformer)
# PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
# PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

# pos = posisi token dalam sekuens
# i   = indeks dimensi
# d_model = dimensi embedding

# Alternatif modern: Rotary Position Embedding (RoPE)
# Digunakan oleh Llama, Mistral, Qwen — lebih baik untuk ekstrapolasi posisi

Pre-Training

Pre-training adalah tahap paling intensif secara komputasi. Model belajar dari data teks masif (biasanya triliunan token) menggunakan objective next-token prediction (causal language modeling). Pada tahap ini, model membangun pemahaman fundamental tentang bahasa: tata bahasa, fakta dunia, pola reasoning, dan kemampuan coding.

  • Data: Web crawl (Common Crawl), Wikipedia, GitHub, buku, artikel ilmiah
  • Objective: Autoregressive language modeling — prediksi token berikutnya
  • Infrastruktur: Ribuan GPU selama berminggu-minggu/bulan
  • Hasil: Base model yang "tahu banyak" tapi tidak bisa mengikuti instruksi dengan baik

Supervised Fine-Tuning (SFT)

Supervised Fine-Tuning (SFT) atau Instruction Tuning: model base dilatih lebih lanjut dengan dataset berkualitas tinggi berisi pasangan (instruksi, respons). Tujuannya adalah mengajarkan model untuk mengikuti instruksi pengguna dengan format yang tepat.

Alignment: RLHF vs DPO

Alignment bertujuan menyelaraskan output model dengan preferensi dan nilai-nilai manusia. Dua pendekatan utama:

AspekRLHFDPO
KomponenReward Model + RL (PPO)Preference pairs + binary cross-entropy
KompleksitasTinggi — 3 model (actor, critic, reward)Rendah — langsung pada policy model
StabilitasSulit di-tune, reward hackingStabil, supervised learning
PenggunaChatGPT, Claude, GeminiLlama 3, Mixtral, Qwen

4.6 Inference LLM

Proses Inference

Inference adalah proses menghasilkan teks dari model yang sudah dilatih. Ini berjalan secara autoregressive: model menghasilkan satu token pada satu waktu, dan setiap token baru ditambahkan ke input untuk menghasilkan token berikutnya.

4.7 Ringkasan

  • LLM adalah model bahasa berbasis Transformer dengan miliaran parameter, dilatih pada triliunan token untuk memahami dan menghasilkan teks.
  • Tokenisasi (BPE, WordPiece) mengonversi teks menjadi token. BPE banyak digunakan oleh GPT-series dan Llama; WordPiece oleh BERT dan Google models.
  • Arsitektur Transformer menggunakan self-attention, multi-head attention, dan positional encoding. Tiga varian utama: encoder-only (BERT), decoder-only (GPT), dan encoder-decoder (T5).
  • Training LLM terdiri dari pre-training → supervised fine-tuning (SFT) → alignment (RLHF atau DPO).
  • Inference berjalan autoregressive (token demi token). Optimasi: KV Cache, quantization, speculative decoding, Flash Attention.

🏋️ Latihan

  1. Eksplorasi Tokenizer: Gunakan TikTokenizer untuk memasukkan teks dalam bahasa Indonesia dan bahasa Inggris. Bandingkan jumlah token yang dihasilkan. Amati bagaimana kata majemuk bahasa Indonesia dipecah.
  2. Visualisasi Attention: Coba BertViz untuk memvisualisasikan attention heads dalam model BERT. Perhatikan bagaimana head-head berbeda fokus pada aspek yang berbeda (sintaksis, semantik).
  3. Hitung Parameter: Hitung jumlah parameter sebuah Transformer layer dengan d_model=4096, d_ff=14336, n_heads=32. (Hint: 4 × d_model² untuk Q,K,V,O projection + 2 × d_model × d_ff untuk FFN).
  4. Inference dengan Quantization: Gunakan llama.cpp atau Ollama untuk melakukan inference model Llama 3 8B dengan Q4_K_M quantization. Bandingkan kualitas output dengan versi FP16.
