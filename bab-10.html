10.1 Definisi & Mengapa Agentic AI Muncul

Definisi Agentic AI

Agentic AI (atau AI Agent) adalah sistem AI yang memiliki kemampuan untuk bertindak secara otonom — merencanakan langkah-langkah, menggunakan tools, mengingat konteks, dan beradaptasi berdasarkan hasil — untuk menyelesaikan tugas kompleks yang membutuhkan multiple steps. Berbeda dengan LLM tradisional yang hanya merespons prompt, AI Agent secara proaktif mengambil inisiatif dan membuat keputusan.

📖 Analogi: Jika Chatbot adalah "asisten yang menjawab pertanyaan Anda," AI Agent adalah "karyawan yang Anda beri tugas dan dia mencari tahu sendiri cara menyelesaikannya."

10.3 Komponen AI Agent

10.3.1 Planner

Planner adalah komponen yang bertanggung jawab untuk memecah tujuan besar menjadi langkah-langkah kecil yang dapat dieksekusi. Planner menggunakan LLM reasoning (Chain-of-Thought, Tree-of-Thought) untuk menghasilkan rencana aksi.

# Contoh Planner sederhana
def plan_task(objective: str) -> list[dict]:
    """Planner: pecah objective menjadi action steps"""
    prompt = f"""You are a task planner. Break down this objective 
into actionable steps. For each step, specify the tool needed.

Objective: {objective}

Respond in JSON format:
[{{"step": 1, "action": "...", "tool": "...", "args": {{}}}}]"""
    
    response = llm.generate(prompt)
    plan = json.loads(response)
    return plan

10.3.3 Tool Calling

Tool Calling adalah kemampuan Agent untuk menggunakan alat eksternal: API, database query, code execution, file operations, web search, dll. Tools memberi Agent kemampuan untuk bertindak di dunia nyata, bukan hanya menghasilkan teks.

            "type": "object",

                "to": {"type": "string"},
                "subject": {"type": "string"},
                "body": {"type": "string"}

def agent_loop(user_request):
    messages = [{"role": "user", "content": user_request}]
    
    while True:
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=tools
        )
        
        msg = response.choices[0].message
        
        if msg.tool_calls:
            # Agent memutuskan untuk menggunakan tools
            for tool_call in msg.tool_calls:
                result = execute_tool(tool_call)
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": result
                })
        else:
            # Agent selesai, return final answer
            return msg.content

10.3.4 Reflection

Reflection adalah kemampuan Agent untuk mengevaluasi hasil tindakannya sendiri dan memperbaiki kesalahan. Setelah melakukan aksi, Agent memeriksa apakah hasilnya sesuai ekspektasi. Jika tidak, Agent merevisi rencana dan mencoba lagi.

def reflect_and_retry(action_result, expected_outcome):
    """Reflection: evaluasi hasil dan retry jika perlu"""
    prompt = f"""Evaluate the action result against expected outcome.
    
Expected: {expected_outcome}
Actual Result: {action_result}

Is the result satisfactory? If not, what went wrong and how to fix it?
Respond in JSON: {{"success": bool, "analysis": str, "next_action": str}}"""
    
    reflection = llm.generate(prompt)
    result = json.loads(reflection)
    
    if not result["success"]:
        # Agent belajar dari kesalahan dan mencoba lagi
        return result["next_action"]
    return None  # Success

10.3.5 Multi-Agent

Multi-Agent adalah arsitektur di mana beberapa Agent spesialis bekerja bersama untuk menyelesaikan tugas kompleks. Setiap Agent memiliki peran spesifik (researcher, writer, reviewer, coder) dan berkomunikasi satu sama lain.

10.4 Agent Workflow: Plan → Execute → Observe → Reflect

AI Agent beroperasi dalam loop berkelanjutan yang terdiri dari empat fase. Loop ini berulang sampai task selesai atau batas maksimum tercapai.

flowchart LR P["📋 Plan\nBreak down task\ninto steps"] --> E["⚡ Execute\nRun tool calls\nperform actions"] E --> O["👁️ Observe\nCollect results\ncheck outputs"] O --> D{"✅ Done?"} D -->|"No"| R["🪞 Reflect\nAnalyze what went\nwrong, learn"] R --> P D -->|"Yes"| F["🏁 Final Output"] style P fill:#eff6ff,stroke:#3b82f6 style E fill:#f0fdf4,stroke:#22c55e style O fill:#fffbeb,stroke:#f59e0b style R fill:#fef3c7,stroke:#f59e0b style F fill:#dcfce7,stroke:#22c55e

Fase 1: Plan

Agent menganalisis task dan memecahnya menjadi langkah-langkah yang dapat dieksekusi. Planner menggunakan LLM reasoning seperti Chain-of-Thought atau ReAct (Reasoning + Acting).

Fase 2: Execute

Agent mengeksekusi langkah demi langkah, memanggil tools yang diperlukan (API, database, code execution). Setiap eksekusi menghasilkan output yang dicatat.

Fase 3: Observe

Agent mengamati hasil eksekusi. Apakah output sesuai ekspektasi? Apakah ada error? Apakah task sudah selesai? Hasil observasi disimpan di working memory.

Fase 4: Reflect

Jika hasil tidak sesuai, Agent melakukan refleksi: menganalisis penyebab kegagalan, belajar dari kesalahan, dan merevisi rencana. Jika berhasil, Agent melanjutkan ke langkah berikutnya atau menyelesaikan task.

10.5 Autonomous Task vs Human-in-the-Loop

Autonomous Task

Agent menjalankan seluruh task tanpa intervensi manusia. Cocok untuk task yang terdefinisi jelas, repetitif, dan memiliki risiko rendah jika terjadi kesalahan.

📊 Data Processing

ETL pipeline otomatis

📧 Email Sorting

Klasifikasi dan routing email otomatis

🔍 Monitoring

System monitoring dan alerting otomatis

📝 Report Generation

Generate laporan periodik otomatis

Human-in-the-Loop (HITL)

Agent meminta persetujuan atau input manusia pada titik-titik kritis sebelum melanjutkan. Cocok untuk task dengan risiko tinggi, keputusan yang memerlukan judgment manusia, atau compliance requirements.

💰 Financial Decisions

Approve transaksi di atas threshold tertentu

⚖️ Legal Documents

Review kontrak sebelum dikirim ke client

🏥 Medical Diagnosis

Verifikasi hasil diagnosa oleh dokter

🚀 Production Deploy

Approve deployment ke production

⚠️ Kapan memilih HITL? Jika kesalahan Agent dapat menyebabkan kerugian finansial, masalah hukum, atau risiko keselamatan — selalu gunakan Human-in-the-Loop. Jangan biarkan Agent fully autonomous untuk keputusan kritis.

Contoh: OpenAI Agents SDK

from agents import Agent, Runner, function_tool

@function_tool
def search_kb(query: str) -> str:
    """Search internal knowledge base"""
    # Implementasi search
    return f"Results for: {query}"

@function_tool  
def send_email(to: str, subject: str, body: str) -> str:
    """Send an email"""
    # Implementasi email
    return f"Email sent to {to}"

# Definisikan Agent spesialis
researcher = Agent(
    name="Researcher",
    instructions="Search and gather information. Be thorough.",
    tools=[search_kb]
)

writer = Agent(
    name="Writer", 
    instructions="Write clear, concise summaries based on research.",
)

reviewer = Agent(
    name="Reviewer",
    instructions="Review content for accuracy and clarity.",
)

# Orchestrator dengan handoffs
orchestrator = Agent(
    name="Orchestrator",
    instructions="""Coordinate research → writing → review workflow.
    Hand off to researcher first, then writer, then reviewer.""",
    handoffs=[researcher, writer, reviewer]
)

# Run agent
result = Runner.run_sync(
    orchestrator, 
    "Create a summary of our Q3 performance"
)
print(result.final_output)

Contoh: LangGraph

from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated
import operator

class AgentState(TypedDict):
    messages: Annotated[list, operator.add]
    plan: list
    current_step: int
    final_output: str

def planner(state: AgentState) -> AgentState:
    """Plan the next action"""
    # LLM-based planning logic
    return state

def executor(state: AgentState) -> AgentState:
    """Execute the planned action"""
    # Tool execution logic
    return state

def observer(state: AgentState) -> AgentState:
    """Observe and evaluate results"""
    return state

def should_continue(state: AgentState) -> str:
    """Decide whether to continue or finish"""
    if state["current_step"] >= len(state["plan"]):
        return "end"
    return "execute"

# Build graph
graph = StateGraph(AgentState)
graph.add_node("plan", planner)
graph.add_node("execute", executor) 
graph.add_node("observe", observer)

graph.set_entry_point("plan")
graph.add_edge("plan", "execute")
graph.add_edge("execute", "observe")
graph.add_conditional_edges("observe", should_continue, {
    "execute": "execute",
    "end": END
})

app = graph.compile()
result = app.invoke({"messages": [], "plan": [], "current_step": 0})

10.8 Ringkasan

  • Agentic AI adalah sistem AI otonom yang merencanakan, menggunakan tools, dan beradaptasi — melampaui Chatbot yang hanya merespons teks.
  • Komponen inti: Planner (pemecahan tugas), Memory (short/long/working), Tool Calling (aksi nyata), Reflection (evaluasi diri), Multi-Agent (kolaborasi spesialis).
  • Workflow: Plan → Execute → Observe → Reflect dalam loop berkelanjutan hingga task selesai.
  • Autonomous vs HITL: Gunakan autonomous untuk task rendah risiko; Human-in-the-Loop untuk keputusan kritis (finansial, legal, medis).
  • Framework: OpenAI Agents SDK (simple), LangGraph (stateful workflows), CrewAI (multi-agent roles), AutoGen (conversational), Semantic Kernel (enterprise .NET), Google ADK (Gemini-native).
