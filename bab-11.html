11.1 REST API & Authentication

Authentication Methods

Semua AI API menggunakan API Key atau Bearer Token untuk authentication. Kunci disimpan di environment variable dan dikirim melalui HTTP header.

ProviderAuth MethodHeaderBase URL
OpenAIBearer TokenAuthorization: Bearer sk-...https://api.openai.com/v1
Google GeminiAPI Key (query param atau header)x-goog-api-key: AIza...https://generativelanguage.googleapis.com/v1beta
DeepSeekBearer TokenAuthorization: Bearer sk-...https://api.deepseek.com/v1
⚠️ Security: JANGAN PERNAH hardcode API key di source code! Simpan di .env file dan akses melalui config/services.php atau env() helper.

Chat Completion

apiKey = config('services.openai.api_key');
        $this->baseUrl = config('services.openai.base_url');
        $this->timeout = config('services.openai.timeout', 60);
    }

    /**
     * Send a chat completion request to OpenAI.
     *
     * @param array $messages Array of message objects with 'role' and 'content'
     * @param string $model Model name (default: gpt-4o)
     * @param array $options Additional options (temperature, max_tokens, etc.)
     * @return array Response from OpenAI
     */
    public function chatCompletion(
        array $messages,
        string $model = 'gpt-4o',
        array $options = []
    ): array {
        $payload = array_merge([
            'model' => $model,
            'messages' => $messages,
            'temperature' => 0.7,
            'max_tokens' => 4096,
        ], $options);

        try {
            $response = Http::timeout($this->timeout)
                ->withHeaders([
                    'Authorization' => "Bearer {$this->apiKey}",
                    'Content-Type' => 'application/json',
                ])
                ->post("{$this->baseUrl}/chat/completions", $payload);

            if ($response->failed()) {
                throw new \RuntimeException(
                    "OpenAI API error: {$response->body()}",
                    $response->status()
                );
            }

            return $response->json();
        } catch (ConnectionException $e) {
            throw new \RuntimeException(
                "OpenAI connection failed: {$e->getMessage()}",
                0,
                $e
            );
        }
    }

    /**
     * Simple chat — send a prompt and get text response.
     */
    public function chat(string $prompt, string $model = 'gpt-4o'): string
    {
        $result = $this->chatCompletion([
            ['role' => 'user', 'content' => $prompt]
        ], $model);

        return $result['choices'][0]['message']['content'] ?? '';
    }

    /**
     * Chat with system prompt for context.
     */
    public function chatWithSystem(
        string $systemPrompt,
        string $userMessage,
        string $model = 'gpt-4o'
    ): string {
        $result = $this->chatCompletion([
            ['role' => 'system', 'content' => $systemPrompt],
            ['role' => 'user', 'content' => $userMessage],
        ], $model);

        return $result['choices'][0]['message']['content'] ?? '';
    }
}

11.3 Integrasi Google Gemini API

apiKey = config('services.gemini.api_key');

            'https://generativelanguage.googleapis.com/v1beta');

    /**
     * Generate content using Gemini API.
     *
     * @param string $prompt User prompt text
     * @param string $model Model name (default: gemini-2.0-flash)
     * @param array $options Generation config
     * @return array Decoded response
     */
    public function generateContent(
        string $prompt,
        string $model = 'gemini-2.0-flash',
        array $options = []
    ): array {
        $url = "{$this->baseUrl}/models/{$model}:generateContent";

        $payload = array_merge([
            'contents' => [
                [
                    'parts' => [
                        ['text' => $prompt]
                    ]
                ]
            ],
            'generationConfig' => [
                'temperature' => 0.7,
                'maxOutputTokens' => 4096,
                'topP' => 0.95,
                'topK' => 40,
            ]
        ], $options);

        $response = Http::timeout(60)
            ->withHeaders([
                'x-goog-api-key' => $this->apiKey,
                'Content-Type' => 'application/json',
            ])
            ->post($url, $payload);

        if ($response->failed()) {
            throw new \RuntimeException(
                "Gemini API error [{$response->status()}]: {$response->body()}"
            );
        }

        return $response->json();
    }

    /**
     * Simple text generation with Gemini.
     */
    public function generate(string $prompt, string $model = 'gemini-2.0-flash'): string
    {
        $result = $this->generateContent($prompt, $model);

        return $result['candidates'][0]['content']['parts'][0]['text']
            ?? throw new \RuntimeException('Empty Gemini response');
    }

    /**
     * Generate with system instruction.
     */
    public function generateWithSystemInstruction(
        string $systemInstruction,
        string $prompt,
        string $model = 'gemini-2.0-flash'
    ): string {
        $url = "{$this->baseUrl}/models/{$model}:generateContent";

        $payload = [
            'systemInstruction' => [
                'parts' => [['text' => $systemInstruction]]
            ],
            'contents' => [
                [
                    'parts' => [['text' => $prompt]]
                ]
            ]
        ];

        $response = Http::timeout(60)
            ->withHeaders([
                'x-goog-api-key' => $this->apiKey,
                'Content-Type' => 'application/json',
            ])
            ->post($url, $payload);

        $result = $response->json();
        return $result['candidates'][0]['content']['parts'][0]['text'] ?? '';
    }
}

11.4 Integrasi DeepSeek API

DeepSeek API kompatibel dengan OpenAI SDK format, sehingga dapat menggunakan struktur payload yang sama.

apiKey = config('services.deepseek.api_key');
        $this->baseUrl = config('services.deepseek.base_url',

    }

    /**
     * Chat completion using DeepSeek API (OpenAI-compatible).
     *
     * @param array $messages Message array
     * @param string $model 'deepseek-chat' or 'deepseek-reasoner'
     * @param array $options Additional parameters
     * @return array API response
     */
    public function chatCompletion(
        array $messages,
        string $model = 'deepseek-chat',
        array $options = []
    ): array {
        $payload = array_merge([
            'model' => $model,
            'messages' => $messages,
            'temperature' => 0.7,
            'max_tokens' => 4096,
            'stream' => false,
        ], $options);

        $response = Http::timeout(90)
            ->withHeaders([
                'Authorization' => "Bearer {$this->apiKey}",
                'Content-Type' => 'application/json',
                'Accept' => 'application/json',
            ])
            ->post("{$this->baseUrl}/chat/completions", $payload);

        if ($response->failed()) {
            throw new \RuntimeException(
                "DeepSeek API error: {$response->body()}",
                $response->status()
            );
        }

        return $response->json();
    }

    /**
     * Simple chat with DeepSeek.
     */
    public function chat(string $prompt, string $model = 'deepseek-chat'): string
    {
        $result = $this->chatCompletion([
            ['role' => 'user', 'content' => $prompt]
        ], $model);

        return $result['choices'][0]['message']['content'] ?? '';
    }

    /**
     * Use DeepSeek Reasoner (R1) for complex reasoning tasks.
     */
    public function reason(string $prompt): string
    {
        return $this->chat($prompt, 'deepseek-reasoner');
    }
}

            if ($response->serverError() || $response->status() === 429) {
                $attempt++;
                if ($attempt < $maxRetries) {
                    $delay = $baseDelayMs * pow(2, $attempt - 1);

                    $retryAfter = $response->header('Retry-After');

                $delay = $baseDelayMs * pow(2, $attempt - 1);
                usleep($delay * 1000);
                goto retry;
            }
            throw $e;

                CURLOPT_URL => "{$this->baseUrl}/chat/completions",
                CURLOPT_POST => true,
                CURLOPT_POSTFIELDS => json_encode($payload),
                CURLOPT_HTTPHEADER => [
                    "Authorization: Bearer {$this->apiKey}",
                    "Content-Type: application/json",
                ],
                CURLOPT_WRITEFUNCTION => function ($ch, $data) {
                    // Parse SSE stream: "data: {...}\n\n"
                    $lines = explode("\n", $data);
                    foreach ($lines as $line) {
                        if (str_starts_with($line, 'data: ')) {
                            $json = substr($line, 6);
                            if ($json === '[DONE]') {
                                echo "data: [DONE]\n\n";
                                ob_flush(); flush();
                                return strlen($data);
                            }
                            $decoded = json_decode($json, true);
                            $content = $decoded['choices'][0]['delta']['content']
                                ?? '';
                            if ($content) {
                                echo "data: " . json_encode([
                                    'content' => $content
                                ]) . "\n\n";
                                ob_flush(); flush();
                            }
                        }
                    }
                    return strlen($data);
                },
                CURLOPT_TIMEOUT => 120,
            ]);

            curl_exec($ch);

            if (curl_errno($ch)) {
                echo "data: " . json_encode([
                    'error' => curl_error($ch)
                ]) . "\n\n";
            }

            curl_close($ch);
        }, 200, [
            'Content-Type' => 'text/event-stream',
            'Cache-Control' => 'no-cache',
            'X-Accel-Buffering' => 'no',
            'Connection' => 'keep-alive',
        ]);
    }

11.6.4 Best Practice Ringkasan

Best PracticeImplementasi
Rate LimitingGunakan Laravel RateLimiter dengan key per-user. Beri tier berbeda (free vs premium).
Error HandlingWrap API calls dengan try-catch. Klasifikasikan error (4xx client error, 5xx server error, timeout, rate limit).
Retry LogicExponential backoff dengan jitter. Retry hanya pada 5xx dan 429. Max 3 retries.
StreamingGunakan Server-Sent Events (SSE) untuk streaming response. Laravel StreamedResponse + cURL.
LoggingLog setiap API call: model, token count, latency, cost, error. Gunakan dedicated log channel.
CachingCache frequent/identical requests. Gunakan hash dari prompt + parameters sebagai cache key.

11.8 Ringkasan

  • Integrasi AI dengan Laravel menggunakan HTTP Client untuk memanggil REST API OpenAI, Gemini, dan DeepSeek dengan Bearer Token authentication.
  • Service class pattern memisahkan logic API call dari controller: OpenAIService, GeminiService, DeepSeekService — masing-masing dengan method chat, chatCompletion, streaming.
  • Route + Controller + Middleware: Route prefix /api/ai/chat/{provider} dengan auth:sanctum, rate limiting, dan request validation.
  • Best Practice: Rate limiting per-user, exponential backoff retry untuk 5xx/429 errors, SSE streaming response untuk UX real-time, logging setiap API call, caching repetitive requests.
  • Security: API key di .env, jangan hardcode. Gunakan Laravel config/services.php untuk konfigurasi terpusat.
