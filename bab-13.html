13.1 Monitoring: Metrics, Latency & Throughput

Monitoring aplikasi AI berbeda dari aplikasi tradisional. Selain metrik standar (CPU, memory, request rate), aplikasi AI memerlukan monitoring spesifik: token usage, model latency, cost, dan kualitas output.

Implementasi Monitoring dengan Python

# ai_monitor.py — Comprehensive AI monitoring utilities
import time
import functools
from dataclasses import dataclass, field
from typing import Optional
from collections import defaultdict
import statistics
import threading

@dataclass
class AIMetrics:
    """Track per-request AI metrics."""
    provider: str
    model: str
    prompt_tokens: int = 0
    completion_tokens: int = 0
    latency_ms: float = 0.0
    ttft_ms: float = 0.0  # Time to First Token
    cost_usd: float = 0.0
    status: str = "success"
    error: Optional[str] = None

class AIMetricsCollector:
    """Collect and aggregate AI metrics."""
    
    def __init__(self):
        self._lock = threading.Lock()
        self.requests: list[AIMetrics] = []
        self.daily_tokens: dict[str, int] = defaultdict(int)
        self.daily_cost: dict[str, float] = defaultdict(float)
    
    def record(self, metrics: AIMetrics):
        with self._lock:
            self.requests.append(metrics)
            date_key = time.strftime("%Y-%m-%d")
            self.daily_tokens[date_key] += (
                metrics.prompt_tokens + metrics.completion_tokens
            )
            self.daily_cost[date_key] += metrics.cost_usd
    
    def get_latency_percentiles(self) -> dict:
        """Calculate P50, P95, P99 latency."""
        if not self.requests:
            return {}
        latencies = sorted([r.latency_ms for r in self.requests])
        return {
            "p50": statistics.median(latencies),
            "p95": latencies[int(len(latencies) * 0.95)],
            "p99": latencies[int(len(latencies) * 0.99)],
            "avg": statistics.mean(latencies),
            "max": max(latencies),
        }
    
    def get_error_rate(self) -> float:
        """Calculate error rate as percentage."""
        if not self.requests:
            return 0.0
        errors = sum(1 for r in self.requests if r.status == "error")
        return (errors / len(self.requests)) * 100
    
    def get_throughput(self, window_seconds: int = 60) -> float:
        """Calculate requests per second in the given window."""
        now = time.time()
        recent = [
            r for r in self.requests 
            if (now - r.latency_ms / 1000) < window_seconds
        ]
        return len(recent) / window_seconds if recent else 0.0
    
    def get_summary(self) -> dict:
        """Get comprehensive monitoring summary."""
        return {
            "total_requests": len(self.requests),
            "latency": self.get_latency_percentiles(),
            "error_rate_pct": self.get_error_rate(),
            "throughput_rps": self.get_throughput(),
            "daily_tokens": dict(self.daily_tokens),
            "daily_cost_usd": dict(self.daily_cost),
        }

# Global collector instance
metrics_collector = AIMetricsCollector()

def track_ai_metrics(func):
    """Decorator to automatically track AI call metrics."""
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        try:
            result = func(*args, **kwargs)
            latency = (time.time() - start_time) * 1000
            
            # Extract token info from result (implementation-dependent)
            metrics = AIMetrics(
                provider=kwargs.get("provider", "unknown"),
                model=kwargs.get("model", "unknown"),
                prompt_tokens=getattr(result, "prompt_tokens", 0),
                completion_tokens=getattr(result, "completion_tokens", 0),
                latency_ms=latency,
                cost_usd=calculate_cost(
                    kwargs.get("model", ""),
                    getattr(result, "prompt_tokens", 0),
                    getattr(result, "completion_tokens", 0)
                ),
                status="success"
            )
            metrics_collector.record(metrics)
            return result
        except Exception as e:
            latency = (time.time() - start_time) * 1000
            metrics = AIMetrics(
                provider=kwargs.get("provider", "unknown"),
                model=kwargs.get("model", "unknown"),
                latency_ms=latency,
                status="error",
                error=str(e)
            )
            metrics_collector.record(metrics)
            raise
    
    return wrapper

MODEL_PRICING = {
    "gpt-4o": {"input": 2.50, "output": 10.00},
    "gpt-4o-mini": {"input": 0.15, "output": 0.60},
    "gpt-4-turbo": {"input": 10.00, "output": 30.00},
    "claude-3.5-sonnet": {"input": 3.00, "output": 15.00},
    "deepseek-chat": {"input": 0.27, "output": 1.10},
    "gemini-2.0-flash": {"input": 0.10, "output": 0.40},

def calculate_cost(model: str, prompt_tokens: int, 
                   completion_tokens: int) -> float:
    """Calculate cost in USD for an API call."""
    pricing = MODEL_PRICING.get(model, {"input": 0, "output": 0})
    input_cost = (prompt_tokens / 1_000_000) * pricing["input"]
    output_cost = (completion_tokens / 1_000_000) * pricing["output"]
    return round(input_cost + output_cost, 6)

class CostTracker:
    """Track AI costs with budget alerts."""
    
    def __init__(self, daily_budget_usd: float = 50.0,
                 monthly_budget_usd: float = 1000.0):
        self.daily_budget = daily_budget_usd
        self.monthly_budget = monthly_budget_usd
        self._daily_costs: dict[str, float] = defaultdict(float)
        self._monthly_costs: dict[str, float] = defaultdict(float)
        self._cost_by_model: dict[str, float] = defaultdict(float)
        self._cost_by_user: dict[str, float] = defaultdict(float)
    
    def track(self, model: str, prompt_tokens: int, 
              completion_tokens: int, user_id: str = "anonymous"):
        """Track a single API call cost."""
        cost = calculate_cost(model, prompt_tokens, completion_tokens)
        
        today = time.strftime("%Y-%m-%d")
        month = time.strftime("%Y-%m")
        
        self._daily_costs[today] += cost
        self._monthly_costs[month] += cost
        self._cost_by_model[model] += cost
        self._cost_by_user[user_id] += cost
        
        # Check budget alerts
        if self._daily_costs[today] > self.daily_budget * 0.8:
            self._send_alert(
                f"⚠️ Daily AI cost at 80%: ${self._daily_costs[today]:.2f}"
            )
        
        if self._daily_costs[today] > self.daily_budget:
            self._send_alert(
                f"🚨 Daily AI budget exceeded: ${self._daily_costs[today]:.2f}"
            )
    
    def get_cost_report(self) -> dict:
        """Generate cost report."""
        today = time.strftime("%Y-%m-%d")
        month = time.strftime("%Y-%m")
        
        return {
            "today": {
                "cost_usd": round(self._daily_costs[today], 4),
                "budget_remaining": round(
                    self.daily_budget - self._daily_costs[today], 4
                ),
                "budget_pct": round(
                    self._daily_costs[today] / self.daily_budget * 100, 1

            "this_month": {
                "cost_usd": round(self._monthly_costs[month], 4),
                "budget_remaining": round(
                    self.monthly_budget - self._monthly_costs[month], 4
                ),
            },
            "by_model": {
                model: round(cost, 4) 
                for model, cost in self._cost_by_model.items()
            },
            "by_user": {
                user: round(cost, 4) 
                for user, cost in self._cost_by_user.items()
            }
        }

13.3 Retry Strategy & Error Handling

Exponential Backoff Retry

Retry strategy yang tepat adalah kunci reliability aplikasi AI. Gunakan exponential backoff dengan jitter untuk menghindari thundering herd problem.

# retry.py — Exponential backoff with jitter
import time
import random
import functools
from typing import Type, Tuple

class RetryExhausted(Exception):
    """Raised when all retries are exhausted."""
    pass

def retry_with_backoff(
    max_retries: int = 3,
    base_delay_seconds: float = 1.0,
    max_delay_seconds: float = 60.0,
    backoff_factor: float = 2.0,
    jitter: bool = True,
    retryable_exceptions: Tuple[Type[Exception], ...] = (
        ConnectionError, TimeoutError
    ),
    retryable_status_codes: Tuple[int, ...] = (429, 500, 502, 503, 504)
):
    """
    Decorator: retry function with exponential backoff.
    
    Only retries on retryable_exceptions and HTTP status codes
    that indicate transient failures (rate limits, server errors).
    """
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            last_exception = None
            
            for attempt in range(max_retries + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    last_exception = e
                    
                    # Don't retry if not retryable
                    if not isinstance(e, retryable_exceptions):
                        # Check if it's an HTTP error with retryable status
                        if hasattr(e, 'status_code'):
                            if e.status_code not in retryable_status_codes:
                                raise
                        else:
                            raise
                    
                    if attempt == max_retries:
                        raise RetryExhausted(
                            f"Failed after {max_retries} retries. "
                            f"Last error: {last_exception}"
                        )
                    
                    # Calculate delay with exponential backoff
                    delay = min(
                        base_delay_seconds * (backoff_factor ** attempt),
                        max_delay_seconds
                    )
                    
                    # Add jitter (+/- 25%) to avoid thundering herd
                    if jitter:
                        delay = delay * (0.75 + random.random() * 0.5)
                    
                    print(
                        f"Retry {attempt + 1}/{max_retries} "
                        f"after {delay:.2f}s — {e}"
                    )
                    time.sleep(delay)
            
            raise last_exception
        
        return wrapper
    return decorator

# Usage example
@retry_with_backoff(
    max_retries=3,
    base_delay_seconds=1.0,
    jitter=True
)
def call_openai_api(messages, model="gpt-4o"):
    response = client.chat.completions.create(
        model=model,
        messages=messages
    )
    return response

# Error handler with circuit breaker + graceful degradation
from datetime import datetime, timedelta

class CircuitBreaker:
    def __init__(self, failure_threshold=5, recovery_timeout=30):
        self.failure_count = 0
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.last_failure_time = None
        self.state = "CLOSED"  # CLOSED, OPEN, HALF_OPEN
    
    def call(self, func, *args, **kwargs):
        if self.state == "OPEN":
            if (datetime.now() - self.last_failure_time).seconds > self.recovery_timeout:
                self.state = "HALF_OPEN"
            else:
                raise Exception("Circuit breaker is OPEN")
        
        try:
            result = func(*args, **kwargs)
            if self.state == "HALF_OPEN":
                self.state = "CLOSED"
                self.failure_count = 0
            return result
        except Exception as e:
            self.failure_count += 1
            self.last_failure_time = datetime.now()
            
            if self.failure_count >= self.failure_threshold:
                self.state = "OPEN"
            
            raise e

# Combined: retry + circuit breaker + graceful degradation
class ResilientAIService:
    def __init__(self):
        self.circuit_breaker = CircuitBreaker()
        self.model_fallback = {
            "gpt-4o": "gpt-4o-mini",
            "claude-3.5-sonnet": "claude-3-haiku",
        }
    
    @retry_with_backoff(max_retries=2)
    def call_with_resilience(self, model: str, messages: list):
        try:
            return self.circuit_breaker.call(
                self._call_model, model, messages
            )
        except Exception as e:
            # Graceful degradation: try fallback model
            fallback = self.model_fallback.get(model)
            if fallback:
                print(f"Falling back from {model} to {fallback}")
                return self._call_model(fallback, messages)
            raise e

# prompt_manager.py — Load versioned prompts from Git
import yaml
import os
from pathlib import Path
from typing import Any

class PromptManager:
    """Manage versioned prompts stored as YAML files in Git."""
    
    def __init__(self, prompts_dir: str = "prompts"):
        self.prompts_dir = Path(prompts_dir)
        self._cache: dict[str, dict] = {}
    
    def load_prompt(self, prompt_name: str, version: str = None) -> dict:
        """
        Load a prompt by name. If version specified, load from 
        Git history, otherwise load current version.
        """
        cache_key = f"{prompt_name}:{version or 'latest'}"
        
        if cache_key in self._cache:
            return self._cache[cache_key]
        
        filepath = self.prompts_dir / f"{prompt_name}.yaml"
        
        if version:
            # Load specific version from Git
            content = self._git_show(filepath, version)
            prompt = yaml.safe_load(content)
        else:
            # Load current version from disk
            with open(filepath, 'r') as f:
                prompt = yaml.safe_load(f)
        
        self._cache[cache_key] = prompt
        return prompt
    
    def render_prompt(self, prompt_name: str, 
                      variables: dict[str, Any],
                      version: str = None) -> str:
        """Load and render a prompt with variables."""
        prompt = self.load_prompt(prompt_name, version)
        template = prompt["prompt"]
        
        # Validate required variables
        required = prompt.get("variables", [])
        missing = [v for v in required if v not in variables]
        if missing:
            raise ValueError(
                f"Missing required variables for '{prompt_name}': {missing}"
            )
        
        return template.format(**variables)
    
    def list_versions(self, prompt_name: str) -> list[str]:
        """List all Git versions of a prompt file."""
        filepath = self.prompts_dir / f"{prompt_name}.yaml"
        # git log --follow --format=%H -- prompts/chat/system_prompt.yaml
        result = os.popen(
            f'git log --follow --format="%H %ai %s" -- {filepath}'
        ).read()
        
        versions = []
        for line in result.strip().split('\n'):
            if line:
                parts = line.split(' ', 3)
                versions.append({
                    "commit": parts[0],
                    "date": f"{parts[1]} {parts[2]}",
                    "message": parts[3] if len(parts) > 3 else ""
                })
        return versions
    
    def _git_show(self, filepath: Path, version: str) -> str:
        """Retrieve file content at a specific Git commit."""
        return os.popen(
            f'git show {version}:{filepath}'
        ).read()

13.5 A/B Testing Prompts

A/B testing memungkinkan Anda membandingkan dua versi prompt untuk menentukan mana yang menghasilkan output lebih baik — baik dari segi kualitas, engagement, maupun conversion.

A/B Testing Implementation

# ab_testing.py — A/B testing framework for AI prompts
import hashlib
import random
from dataclasses import dataclass, field
from typing import Optional

@dataclass
class ABExperiment:
    """Define an A/B test experiment."""
    id: str
    name: str
    variants: list[str]  # List of prompt version names
    traffic_split: list[float]  # e.g., [0.5, 0.5] for 50/50
    metrics: list[str] = field(default_factory=lambda: [
        "user_satisfaction", "response_length", "latency", "cost"
    ])
    min_sample_size: int = 100

class ABTestingEngine:
    """A/B testing engine for AI prompts."""
    
    def __init__(self):
        self.experiments: dict[str, ABExperiment] = {}
        self.results: dict[str, dict] = {}
    
    def create_experiment(self, experiment: ABExperiment):
        """Register a new A/B test experiment."""
        assert abs(sum(experiment.traffic_split) - 1.0) < 0.001, \
            "Traffic split must sum to 1.0"
        assert len(experiment.variants) == len(experiment.traffic_split), \
            "Variants and traffic_split must have same length"
        
        self.experiments[experiment.id] = experiment
        self.results[experiment.id] = {
            variant: {metric: [] for metric in experiment.metrics}
            for variant in experiment.variants
        }
    
    def assign_variant(self, experiment_id: str, 
                       user_id: str) -> str:
        """
        Deterministically assign a user to a variant.
        Uses hash for consistent assignment (same user → same variant).
        """
        experiment = self.experiments[experiment_id]
        
        # Deterministic assignment using hash
        hash_val = int(
            hashlib.md5(f"{experiment_id}:{user_id}".encode()).hexdigest(), 16
        )
        bucket = (hash_val % 10000) / 10000.0
        
        cumulative = 0
        for variant, split in zip(
            experiment.variants, experiment.traffic_split
        ):
            cumulative += split
            if bucket <= cumulative:
                return variant
        
        return experiment.variants[-1]
    
    def record_result(self, experiment_id: str, variant: str,
                      metrics: dict):
        """Record metrics for a single AI call."""
        if experiment_id not in self.results:
            return
        
        for metric, value in metrics.items():
            if metric in self.results[experiment_id][variant]:
                self.results[experiment_id][variant][metric].append(value)
    
    def get_experiment_results(self, experiment_id: str) -> dict:
        """Calculate aggregated results for an experiment."""
        import statistics
        
        experiment = self.experiments[experiment_id]
        raw = self.results[experiment_id]
        
        results = {}
        for variant in experiment.variants:
            variant_stats = {}
            for metric in experiment.metrics:
                values = raw[variant][metric]
                if values:
                    variant_stats[metric] = {
                        "mean": statistics.mean(values),
                        "stdev": statistics.stdev(values) if len(values) > 1 else 0,
                        "count": len(values),
                        "p50": statistics.median(values),
                    }
            results[variant] = variant_stats
        
        return results
    
    def is_significant(self, experiment_id: str, 
                       metric: str) -> bool:
        """Check if results are statistically significant."""
        results = self.get_experiment_results(experiment_id)
        experiment = self.experiments[experiment_id]
        
        for variant in experiment.variants:
            if results[variant][metric]["count"] < experiment.min_sample_size:
                return False
        
        return True

  • Gunakan deterministic assignment (hash-based) agar user selalu mendapat variant yang sama
  • Tentukan metrik sukses sebelum memulai eksperimen
  • Tunggu sample size minimum sebelum mengambil kesimpulan
  • Dokumentasikan hasil dan pelajaran di Git bersama prompt

13.6 Logging Best Practices

Best PracticePenjelasan
Structured Logging (JSON)Log dalam format JSON untuk memudahkan parsing dan query di sistem log aggregator (ELK, Loki, Datadog).
Log Request/Response (sanitized)Log prompt dan response untuk debugging, tapi sanitasi PII (email, nama, nomor telepon).
Correlation IDSetiap request harus memiliki unique correlation ID untuk tracing end-to-end.
Separate AI Log ChannelGunakan dedicated log stream/topic untuk AI-related logs agar tidak bercampur dengan application logs.
Log Levels yang TepatINFO: request/response normal; WARN: retry, fallback, near rate limit; ERROR: failure after all retries.
Retention PolicySimpan detail log 7-30 hari untuk debugging; aggregate metrics lebih lama untuk trend analysis.
Cost-Aware LoggingLog token counts dan estimated cost di setiap request untuk cost analysis.

13.7 Ringkasan

  • Monitoring: Fokus pada metrik AI-spesifik: P50/P95/P99 latency, TTFT (Time to First Token), TPS (Tokens Per Second), error rate, throughput. Gunakan Prometheus + Grafana.
  • Cost Monitoring: Track cost per model, per user, per hari. Setup daily/monthly budget alerts. Gunakan pricing table untuk kalkulasi real-time.
  • Retry Strategy: Exponential backoff dengan jitter untuk transient errors (5xx, 429). Circuit breaker untuk failure cascade. Graceful degradation dengan model fallback.
  • Prompt Versioning: Kelola prompt sebagai YAML di Git. Track history perubahan, author, dan rationale. Render prompt dengan variable substitution.
  • A/B Testing: Deterministic user assignment (hash-based). Metrik sukses yang jelas. Tunggu sample size minimum sebelum concluding.
  • Logging: Structured JSON logging, correlation ID, sanitasi PII, dedicated AI log channel, cost-aware logging.
